常用设置

共 199 种语言，均已实测可用。常用的几种也会出现在插件弹窗里。

悬停翻译
按住触发键，鼠标划过段落即逐段翻译
划词翻译
选中任意文字，弹出译文气泡
输入框翻译
在输入框按 Alt+Enter，把你写的内容译成下面选的语言（写外语用）

快捷键：Alt+T 或 Alt+A 翻译/恢复整页 · Alt+W 翻译整页（补翻新内容） · 选中文字即翻 · 输入框内 Alt+Enter 译成外语 · 悬停悬浮球展开快捷菜单

高级设置（引擎、API Key、脱敏）
翻译引擎

默认用免费的 Google，够日常使用。AI 档用 官网账号的 credits， 在浏览器里登录官网即可生效（插件不保存任何登录凭据）；也可以自备 API Key 走下面的引擎。

DeepL API Key 免费 50 万字/月

在 deepl.com 免费注册获取，以 ":fx" 结尾为免费版。

DeepSeek API Key

在 platform.deepseek.com 获取，成本约 $0.001/千字。

OpenAI API Key

在 platform.openai.com 获取，使用 gpt-4o-mini。

LibreTranslate 实例地址 （留空用公共实例）

开源、可自托管，隐私最高。见 LibreTranslate。

敏感信息脱敏（Beta）
发送前本地打码邮箱/电话/卡号/证件/API Key，译后自动还原

检测与还原全部在浏览器本地完成，敏感原文不会发往翻译服务商。极少数情况引擎改写占位符会导致该处还原失败（不泄露信息），如遇异常可关闭。

PDF 翻译

整份 PDF 保留排版翻译（含学术论文公式）在网站上进行：pdf.openimmersive.ai →

翻译文件

支持 .srt .ass .html .txt .md：在本地解析，只把文字送去翻译， 时间轴／标签／代码块原样保留。需要保留排版的 PDF、Word 等复杂文档， 请用 在线文档翻译。

🔒 隐私保证 所有翻译请求直接从你的浏览器发往翻译服务商，无中间服务器、无代理、无数据收集。API Key 仅存本地。代码完全开源可审计。
